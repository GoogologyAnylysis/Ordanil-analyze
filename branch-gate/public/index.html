Branch Gate

用 GitHub 真实 ID 认人，一人一个命名空间，只有你能推送到自己的分支

第一步 · 授权

授权后我们会读取你的 GitHub 数字 ID（不可变，改名也不会变），并据此分配唯一命名空间。之后你就可以用正常的 git 命令 push / pull / 提 PR。

第二步 · 领取命名空间

命名空间全仓库唯一。注册后会自动把你加为协作者，并创建分支保护规则——只有你能推送到 {namespace}、{namespace}/* 下的分支，其他人推不动。

第三步 · 开始推送

你已获得仓库的 push 权限。用下面的命令正常克隆、建分支、推送即可。注意：只能推送到你的命名空间 下。
